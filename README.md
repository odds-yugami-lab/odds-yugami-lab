# オッズの歪みラボ

AI競馬予測の**事前予想・買い目・結果・収支を時系列で公開記録**するリポジトリです。

## 運用方針

- 対象: JRA重賞（G1 / G2 / G3）
- 公開資金モデル: 1レース10,000円
- 主な券種: 馬連・3連複
- レース前に最終買い目と購入額を記録
- レース後に的中、不的中、払戻、損益、累計回収率を記録
- 外れたレースも削除せず記録
- 予測モデル本体・内部学習データは公開しません

## 現行購入ルール

現行ルールは corrected V2 です。

1. AI確率を主軸に組合せを評価
2. 馬連はAI確率上位5点、3連複は上位8点を候補化
3. オッズだけを理由に候補外の低確率馬券を追加しない
4. 候補内ではオッズの歪みを資金配分の補助情報として利用
5. 単独的中時に原則10,000円以上の払戻となる最低購入額を確保
6. 1レースの合計購入額は10,000円

## 記録構成

- `predictions/` — 発走前に確定した予想・買い目
- `results/` — レース結果・払戻・収支
- `stats/` — 累計成績・条件別集計
- `methodology/` — 公開可能な検証方針・ルール説明

## 検証について

バックテストと実戦公開成績は分けて扱います。実戦成績は発走前の記録を基準とし、結果判明後に買い目を差し替えません。

2026年の追加バックテスト結果は検証完了後に追記します。
