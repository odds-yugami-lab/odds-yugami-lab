補正版の作成と比較は完了。本番に使う接続・過去レースによる実GitHub往復も完了。発売中の単勝を含む全オッズを使った期限内実行は未確認。次の本番では補正版を明示選択し、すべての取得・保存ゲートを通過したときに限って公開する設定へ移行する。設定の反映と初回本番成功は区別する。

WIN/TOP3のBrier、馬連/3連複/着順付き上位3頭のlog lossは現行版から改善。前半68レース・後半35レースでも着順log lossの改善方向は一致。着順log lossの補正版－現行版は-0.6266、レース単位bootstrap95%区間[-0.8069,-0.4426]。補正版－市場基準は-0.0271、区間[-0.0915,+0.0360]で、市場基準に対する優位性は確定しない。

1番人気のWIN推定は13.7%→22.8%（実績34.0%）、11番人気以下は3.6%→1.7%（実績1.1%）。偏りは軽減したが解消したとは扱わない。馬ごとの的中確率も、次のレースの保証値ではない。

## 調整と評価の分離

1. 保存された学習コードと同じ52項目・設定・件数で、2024年末まで677,533行からWIN/TOP3を別途学習し、2025年47,497行を推論した。元の保存済みモデルは変更していない。
2. 再学習した補正器の係数は保存補正器と完全一致しなかった。`reconstruction_report.json`に差を保持した。再学習モデル専用のPlatt補正器を2025年で作り、完全再現と偽っていない。
3. 2025年の平地重賞130レースから全頭が揃う119レースを係数調整に使用。同着2レース、特徴量と頭数等が揃わない9レースを除外した。除外一覧は先に保存した`fit_report.json`。
4. `softmax(alpha*log(AI強度)+beta*log(単勝の正規化逆数))`を着順付き上位3頭の負の対数尤度で調整。2係数は2025年だけで固定。回収率を最大にする係数探索は行っていない。係数は混合割合そのものではない。
5. 保存済みの2025年末まで学習済みモデルを使う2026年103レースに適用した。2026年は元モデルの偏り診断に既に使われており、完全な未見・独立検証とは呼ばない。係数の学習には2026年のラベルを使っていない。

## 確率と配分

同じ補正後のPlackett-Luce強度から、WIN・TOP3周辺確率、全馬連・全3連複、重複を除いた1点以上の的中確率を計算する。馬連・3連複だけを別々に補正してHと食い違わせない。モデル本体は52特徴量のまま、補正段階で単勝オッズを追加取得する。

配分の目的関数、探索重み、solver設定、合計1万円、100円単位、各券の最低必要額のみというルールは維持。`balanced_A_v3_explicit.py`は明示した強度を読む入力アダプタを追加し、配分算法は変更していない。現行版103レースの全買い目と公式払戻を元の監査に対して再現した。

solverは6%の相対MIPギャップと実行時間制限を持つ近似探索。独立したスワンSの再計算は元のモデル確率を差0で再現したが、57点と59点の配分差があった。両者は同じ1万円・最低額ルールを満たし、公式払戻はいずれも17,100円。良い収益の再実行を選んだものではなく、監査の103レース結果は変更していない。全く同じ入力なら必ず同じ配分になるとは保証しない。一度保存した予測は再推論・上書きせずその原本を再利用する。
