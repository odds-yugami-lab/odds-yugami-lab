# 承認済み：上限1万円・最大30点・余りを残す方式

2026年10月23日にユーザーが承認した変更を実装しました。馬連＋3連複、最大30点、各買い目は単独的中時1万円以上の最低必要額のみ、予算は上限1万円、余りは残します。25点という下限は追加していません。期待払戻Eと的中機会Hは50:50、Eの尺度は旧Aコードにあるmax(AI確率×オッズ)×10000に固定しています。当時のcap30元コードの完全再現ではなく、承認された予算上限版として識別しています。

## 結果を予想に入れない手順

2025年を予想する基礎モデルは2024年末までで学習済みのモデルを使いました。確率補正には2024年の結果だけを使用しています。そのために2023年末までで学習したモデルから2024年の予測を実際に計算し、2024年の124重賞で市場補正係数を決め、2025年の買い目を作る前に係数をGitHubに固定しました。2025年の結果で今回の補正係数を選び直していません。

ただしrecent52候補というモデルの種類は、以前の調査で2025年の比較を経て選んだものです。したがって2025年は、モデル選択とも完全に独立した未知期間ではありません。今回の買い目作成時の結果混入を防いだことと、研究全体で未見の年であることを混同しません。

2026年は以前に計算した両モデルの予測と2025年固定の補正係数を使い、買い方だけを変更しました。2026年も既に何度も検証した期間です。

両年とも、割当プログラムへの入力から着順・結果ラベル・払戻を除き、買い目と金額を先に保存しました。全件のハッシュをGitHubに確定し、変更されていないことを検査した後でJRA公式の実払戻と照合しています。確定オッズから払戻を推測して代用していません。
