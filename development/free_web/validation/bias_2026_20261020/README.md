# 2026年・予想と購入先の偏り検証（2026-10-20）

対象は2026年1月4日～10月18日のJRA平地重賞103レース。障害8レースを除外し、公式結果ページの開催・日・レース番号からrace_codeを取得した。最終出走馬と確定オッズを使う事後診断であり、本番の発走前成績ではない。

## 結論

最終1番人気の平均WIN予測13.7%に対し実績34.0%、11番人気以下は予測3.6%に対し実績1.1%。TOP3も同じ方向にずれる。確率の全体平均が実績に近いことだけでは、オッズ別に期待値を正しく見積もれているとはいえない。

現行balanced_A_v3で全103レースを再配分し、モデル上の予測的中数60.1レースに対して実績31レース。仮想投資1,030,000円、JRA公式払戻593,130円、回収率57.5854%。投入の76.15%が100倍以上へ向かった。元のモデル・補正器・購入ルール・過去の公開記録は変更していない。

## 再計算の入口

公開しているのはコード、公式対象一覧、集計・レース別の診断結果だけ。モデル、内部特徴量、履歴、非公開fixtureをこのディレクトリへ保存しない。

1. このリポジトリの同一commitのfree_webモジュール一式を用意する。作業ディレクトリは既定で`bias_20261020`。必要なら`JRA_BIAS_WORKDIR`と`JRA_MODULE_DIR`を指定する。
2. Libraryスキルで`race_features.parquet`、`jra_features_pilot_2025_2026.parquet`、最新のモデル・履歴・preflight ZIPを取得し、作業ディレクトリの`private_assets`へ配置・展開する。`JRA_MODEL_DIR`、`JRA_HISTORY_DIR`、`JRA_BUNDLE_DIR`による指定も可能。公開GitHubへアップロードしない。
3. 同梱の`official_races.json`を作業ディレクトリに置き、`collect_official.py`、`prepare_inputs.py`の順に実行する。解析対象はそのレースの最終着順・勝敗をモデル入力に含めない52項目。
4. `supplement_checkpoints.py`を実行する。Saudi/Irelandは同一52項目モデルの検証済み確率、Fujiは保存済み原本の確率を再利用し、Swanは非公開の公開情報スナップショットから再推論する。
5. `reconstruct_inputs.py 2026061302010111 2026091209040311 2026101808040711`を実行する。公開の過去出馬表・馬プロフィールから前走を選び、前走日が対象日より前であることを確認する。過去成績は履歴の対象日より前だけを集計する。その後`finalize_predictions.py`を実行する。
6. `collect_odds.py`で全103レースの馬連・3連複全組を取得し、`final_postrace`と組数を検証する。`run_portfolios.py`は現行購入関数の既定設定を固定し、レース別に再開可能な結果を作る。
7. `summarize_bias.py`が人気別・オッズ帯別の集計、補完3レースを除く100レースと原データ96レースの感度確認、HTML・JSON・全買い目入りZIPを作る。配分は全8753点で最低必要額・100円単位・合計1万円を照合し、払戻はJRA公式の金額を使う。

## 確認と限界

- 保存済み4モデルファイルのSHA256は富士Sの発走前記録と一致。既存A_v3の5レース（Sprinters/Fuji/Saudi/Ireland/Swan）の点数と払戻も再現した。
- 一部の延期・中止日の未確定データ、馬番00、重複・部分行を公式対象照合によって排除した。元の全特徴量の時点整合性が証明済みという意味ではない。
- 公開情報で補った3レースを除く100レースでも、人気馬を低く、人気薄を高く見積もる傾向は変わらない。函館スプリントSの1頭の前走直線脚質は未解決として欠損値を保持した。
- 安田記念は2着同着。通常のオッズと払戻の対応が異なるため、公式払戻で計算し、1点が1万円未満の払戻になった事例も含めた。組合せ確率のオッズ帯比較からはこの1レースを除いた。
- 最終出走馬には締切後の取消・除外が反映され得る。最終人気と確定オッズを診断用に使う今回の結果を、発走12分前に取得できた情報による運用成績と混同しない。
- 秋華賞の元のcap30予想30点・仮想112%は別の既存記録。このA_v3事後試算で書き換えない。
- まれな高配当の真の期待値を、この103レースだけで確定することはできない。
